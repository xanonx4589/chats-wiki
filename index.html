Alternet

CHATS

Open-source public lobbies and encrypted private chats.
No accounts. No saved chat history. Windows + Linux.

DOWNLOAD ZIP 










1. Download & unzip the ZIP file.




2. Open the unzipped folder.  Right-click in the folder and select the option to open a Terminal.




3. Type the following command:




WINDOWS:


.\altchats_web.exe ADDRESS KEY


LINUX:


 ./altchats_web ADDRESS KEY


[Replace  ADDRESS with the IP address of the lobby you're connecting to.]




[If connecting to a PRIVATE lobby, replace KEY with the KEY the lobby host gave you; otherwise, leave it blank for OPEN lobbies.]




4. Enter the RELAY PORT number the lobby host gave you.




[If they didn't give you a PORT number, try pressing Enter for the default port, 3333.]




5. When asked for a LOCAL WEB PORT, press Enter for the default port 8080.




[The program may choose a different PORT if the default one is busy on your device.]




6. Open the exact address printed in the Terminal in a web browser.




i.e. http://127.0.0.1:[LOCAL WEB PORT]




7. For hosting lobbies, custom web ports, different Windows versions, and more, please read the README.md file.
